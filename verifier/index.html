Give me a receipt.

This origin has no tools, embeds nothing, and has never spoken to the coordinator that produced your file. It reads the statements inside it and fetches each signing key from the origin that statement names — so what it tells you does not depend on trusting whoever handed you the receipt.

The receipt

Drop the JSON file here, choose it, or paste it below. Nothing is uploaded: the file is read in this tab and the only network requests are for the participants' public key documents.

What it does, in order

  1. Recompute the Merkle root from the statements in the file, and compare it with the root the file states. SPEC.md §12
  2. Reject any statement belonging to a different commitment, and require every statement to agree on what this commitment was going to be.
  3. Resolve each key from the origin inside the signed statement — never from the map the coordinator wrote alongside it.
  4. Check the origin identifies itself as the party the statement names, and that the key was in force at the moment the statement is dated.
  5. Check the receipt accounts for every step its own participants signed up to.
